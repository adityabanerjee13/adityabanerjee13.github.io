# adityabanerjee13.github.io

Personal website of Aditya Banerjee: https://adityabanerjee13.github.io

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (MIT licence), itself based on Minimal Mistakes by Michael Rose. GitHub Pages builds and serves it from the `main` branch.

Where to edit:
- `_config.yml`: name, sidebar bio and links
- `_pages/about.md`: homepage
- `_pages/cv.md`: CV page
- `_publications/`: one Markdown file per paper
- `images/profile.png`: sidebar photo
